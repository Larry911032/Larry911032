# 電學立體書

給國中理化（以及 IGCSE／GCSE）學生的互動電學課本。七堂課從一顆電子講到家裡的插座，每一張圖都是可以轉動、按開關、拉滑桿的 3D 立體圖。

| 課 | 主題 | 立體圖 |
|---|---|---|
| 1 | 電荷與靜電 | 兩顆吊起來的氣球：摩擦、排斥、吸引、靜電感應 |
| 2 | 電流 | 開關、燈泡和兩個安培計，加上電量計數器（I = Q ÷ t） |
| 3 | 電壓 | 在導線上點一下放伏特計探棒，再搭配電位高度圖 |
| 4 | 電阻 | 拖曳滑線變阻器，看兩個安培計一起變化；I–V 圖與導線電阻 |
| 5 | 串聯與並聯 | 同樣兩個燈泡切換兩種接法，點燈泡可以拿掉 |
| 6 | 電功率與電費 | 電錶轉盤、六種家電、超過 20 A 會跳電的無熔絲開關 |
| 7 | 家庭用電與安全 | 火線、中性線、地線，故障、觸電、接地與漏電斷路器 |

每一課都照同樣的流程：**先猜猜看 → 看示範 → 翻開答案 → 動手試 → 挑戰過關（蓋印章）**，接著是課文、名詞小卡（附英文）、小測驗和重點整理。書末有公式總表、名詞索引、綜合測驗和給老師家長的說明。

## 怎麼打開

程式用到 JavaScript 模組，直接雙擊 `index.html` 會被瀏覽器擋下來，要用網頁伺服器開：

```bash
cd electricity-book
python3 -m http.server 8000
# 然後打開 http://localhost:8000
```

也可以在 GitHub 的 Settings → Pages 開啟 GitHub Pages，用網址直接分享給學生。

需要網路連線來載入 three.js（jsDelivr）和字型（Google Fonts）。

## 檔案

```
index.html            頁面骨架
css/book.css          版面與配色（白天是方格筆記紙，夜間是藍晒圖）
js/app.js             路由、課程版面、預測、示範步驟、挑戰印章、測驗、朗讀、進度
js/three-kit.js       3D 工具：舞台、墨線風格、電池、燈泡、電表、開關、變阻器、電子流動
js/circuit.js         電路求解器（節點分析），算出每條導線的電流和每個點的電位
js/widgets.js         課文裡的平面小工具：原子圖、水路比喻、I–V 圖、導線電阻、示波器
js/review.js          書末：公式總表、名詞索引、資料來源
js/lessons/*.js       七堂課的內容和立體圖
```

要修改課文，直接編輯 `js/lessons/` 裡對應的檔案：`bigIdea`、`predict`、`watch`（示範步驟）、`tryIt`、`challenge`、`body`（課文）、`keywords`、`quiz`、`summary`。

## 做別的主題

`PLAYBOOK.md` 是製作手冊：教學流程、視覺設計、程式架構、踩過的坑，以及在新的 Claude 對話裡怎麼開頭。`tools/` 裡有打包（esbuild）和測試（Playwright 截圖、3D 互動測試、課程流程測試）的腳本，用法寫在手冊第六節。

## 說明

- 立體圖用簡化的模型：燈泡電阻固定、電池沒有內電阻，電子的速度和交流電的振動都放慢或加快了。
- 過關印章和測驗分數只存在瀏覽器裡（localStorage）。
- 這本書的形式參考 Techartist 的 3D 物理書《Every Joule》（https://iamtechartist.com/every-joule/）。
